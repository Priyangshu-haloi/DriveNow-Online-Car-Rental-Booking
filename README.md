## 📖 Overview

DriveNow is a modern, front-end-only car rental booking experience designed to feel like a real-world premium rental service. It focuses on clean UI/UX, smooth interactions, and a complete customer journey — from searching for a car to confirming a booking and leaving feedback — all rendered dynamically with plain JavaScript, no frameworks or backend required.

The platform lets you:

- Browse a curated fleet of cars with rich visuals
- Filter cars instantly by type, fuel, transmission, and daily budget
- Complete a booking through a guided modal flow
- View and manage your bookings
- Read and submit customer reviews with star ratings
- Reach out via a built-in contact form

## 🚀 Getting Started

### Prerequisites
Just a web browser — no installations, servers, or build tools needed.

### Run Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/drivenow.git
   ```
2. **Navigate into the project folder**
   ```bash
   cd drivenow
   ```
3. **Open `index.html`** directly in your browser, or serve it locally:
   ```bash
   # Using VS Code Live Server extension, or:
   npx serve .
   ```

That's it — no npm install, no config, no `.env` files.
